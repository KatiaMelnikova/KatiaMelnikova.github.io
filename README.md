# KatiaMelnikova.github.io

Персональный сайт Екатерины Мельниковой. Пересобран из проекта V0 для GitHub Pages: Next.js → статические HTML, CSS и JavaScript. Сервер Vercel не требуется.

## Публикация

1. Распакуйте архив и загрузите **содержимое** папки в корень репозитория `KatiaMelnikova/KatiaMelnikova.github.io`, в ветку `main`. Включите скрытые файлы: папку `.github`, `.gitignore` и `public/.nojekyll`.
2. В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Откройте **Actions → Deploy to GitHub Pages → Run workflow**. При последующих изменениях ветки `main` сборка и публикация запускаются автоматически.
4. После успешного завершения сайт будет доступен по адресу https://katiamelnikova.github.io/.

Если основная ветка называется иначе, измените `branches: [main]` в `.github/workflows/deploy.yml`.

## Локальная работа

Нужны Node.js 22 или новее и pnpm 10.11.0.

```sh
npm install -g pnpm@10.11.0
pnpm install --frozen-lockfile
pnpm dev
```

Проверка версии для публикации:

```sh
pnpm build
pnpm check
pnpm verify
pnpm preview
```

Готовый сайт находится в `out/`. Предпросмотр: http://127.0.0.1:4173. Не открывайте HTML двойным щелчком: сайт использует пути от корня домена.

## Где редактировать

- `app/(ru)/` — русские страницы.
- `app/en/` — английские страницы.
- `components/header.tsx` — меню.
- `components/language-switcher.tsx` — переключатель языка.
- `components/site-layout.tsx` — общий шаблон и локальные шрифты.
- `app/globals.css` — оформление.
- `public/images/` — фотографии и иллюстрации.
- `app/sitemap.ts` — карта сайта.

Тексты русской и английской версий сохранены из архива независимо: автоматический перевод и синхронизация содержания не выполнялись. На страницах `/projects/` и `/en/projects/` в исходнике были изображения-заглушки; они сохранены. Меню «Проекты» ведёт на исходную страницу `/applied-projects/`.

## Что изменено

- Включён статический экспорт, вложенные страницы публикуются как `каталог/index.html`.
- Удалены неиспользуемые компоненты и зависимости V0, неработающий middleware и отключение ошибок TypeScript.
- Шрифт Montserrat поставляется с сайтом, без загрузки Google Fonts при сборке или просмотре.
- Русская и английская версии имеют отдельные корневые шаблоны с правильным `lang`.
- Добавлены заголовки страниц, canonical, языковые альтернативы, robots.txt и карта всех 22 страниц для нового домена.
- Добавлены автоматическая публикация, проверка локальных ссылок и ресурсов, `.nojekyll`.
- Мобильное меню используется также на планшетах, чтобы длинное русское меню не выходило за экран.

Файлы подтверждения Google и Яндекса сохранены из исходника. Подтверждение нового домена в этих сервисах выполняется владельцем аккаунтов отдельно.
